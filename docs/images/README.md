# README images

The root `README.md` references three files in this directory. Add them before
announcing the repository, or GitHub renders a broken-image icon in the first screen.

| file | where it appears | what it has to communicate |
|---|---|---|
| `architecture.png` | directly under the title | the whole system in one glance: one wright, four cast lanes, one reader, and the direction work flows |
| `proof.png` | end of "Why this exists" | the difference between a verified run and a refused one, in the tool's own output |
| `routes.png` | end of "The call sheet" | the five routes and the question that selects each |

Whatever aesthetic you choose, three things must survive it: every model id must be
legible at the width GitHub renders (about 850px), the arrows must make the direction of
work unambiguous, and the refusal in `proof.png` must read as a deliberate stop rather
than a crash.
